FAQ

Answers before you book.

Is this connected to a real hotel backend?

No. This is a complete static front-end booking flow built with HTML, CSS, and JavaScript only.

Does the checkout page process real payments?

No real payment is processed. The payment method choices are included to complete the booking experience.

Can I open the website directly from index.html?

Yes. All links are relative, and booking data is stored locally in the browser using web storage.
